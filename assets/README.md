# Assets

This directory can contain **sanitized** diagrams or screenshots used by the case studies.

Before adding any image, verify that it does **not** expose:

- client or patient names;
- document or identity numbers;
- email addresses or phone numbers;
- financial or clinical information;
- internal URLs, hostnames or IP addresses;
- tokens, API keys or credentials;
- proprietary business rules;
- private infrastructure;
- confidential logos or product names.

Prefer screenshots created with test/demo data.

Recommended structure:

```text
assets/
├── concurrent-hospital-auditing/
├── financial-applications-platform/
├── clinical-record-auditing/
└── clinical-research-management/
```

Use WebP or PNG and keep images reasonably compressed.
