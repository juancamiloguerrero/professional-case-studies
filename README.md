# Professional Case Studies

Anonymized technical case studies from enterprise software projects I have worked on as a Full Stack Developer.

Most of my current professional work lives in private repositories. This repository exists to explain the **engineering context, my contribution, technical decisions and lessons learned** without exposing proprietary source code, client identities, infrastructure details or sensitive data.

> **Confidentiality note**
>
> Product and client names have been generalized. Screenshots, URLs, credentials, internal infrastructure, patient/customer information and proprietary code are intentionally excluded.

## What these projects represent

These projects show different kinds of engineering work:

- building and extending business-critical modules;
- understanding and transforming existing systems;
- working with APIs, data models and business rules;
- improving authentication and application security;
- fixing issues in document-management workflows;
- integrating external services and automating operational processes;
- maintaining software where reliability and traceability matter.

## Core technologies across these projects

`Node.js` · `Express.js` · `MongoDB` · `Mongoose` · `JavaScript` · `TypeScript` · `Next.js` · `EJS` · `REST APIs` · `AWS S3` · `ExcelJS` · `JWT` · `Helmet`

Other tools and integrations appear where relevant inside each case study.

## My engineering approach

**Understand the problem → define the scope → inspect the existing system → design the change → implement → validate → harden → evolve.**

I care about solutions that are not only functional, but also **clear, maintainable, secure and aligned with the actual business process**.
